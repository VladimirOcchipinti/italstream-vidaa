📖 Guida rapida — Come crearlo gratis in 1 minuto:
1️⃣ Gratis con ProtonVPN Free: vai su account.protonvpn.com ➔ menu Downloads ➔ scorri a WireGuard configuration ➔ scegli GNU/Linux, seleziona un server FREE estero (es. Paesi Bassi NL o Svizzera) ➔ premi Create e scarica il file .conf (o copia il testo).
2️⃣ Con NordVPN: vai su my.nordaccount.com ➔ NordVPN ➔ Configura manualmente ➔ WireGuard ➔ scegli Switzerland (Svizzera).
